진행 흐름

성적서 한 건이 작성되어 고객에게 닿기까지의 순서입니다.

  1. 01검사 입력

    S/N을 등록하고 항목별 측정값과 확인 결과를 입력합니다.

    검사자
  2. 02자동 판정

    규격 대비 항목별 판정과 종합 판정이 바로 표시됩니다.

    SYSTEM
  3. 03검토 · 승인

    승인자가 확인하고 서명하면 성적서가 확정됩니다.

    승인자
  4. 04고객 공유

    확정된 성적서만 HS HiTek 조회 화면에 공개됩니다.

    HS HiTek
